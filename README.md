# Gerard Laundry
Program kasir laundry sederhana berbasis terminal untuk menghitung biaya
cucian berdasarkan berat.

## Fitur yang tersedia
- Hitung biaya cuci per kg (Rp 9.500/kg) ditambah biaya antar (Rp 3.000)
- Validasi berat cucian
- Diskon 10% untuk cucian minimal 10 kg
- Pembulatan total bayar ke atas per Rp 100
- Pengecekan uang kurang dan perhitungan kembalian

## Teknologi
- Bahasa pemrograman Go
- Git dan GitHub

## Cara Menjalankan
1. Pastikan Go sudah terinstal (`go version`)
2. Clone repository: `git clone https://github.com/Gerardzr/prakgit.git`
3. Masuk ke folder: `cd prakgit`
4. Jalankan: `go run main.go`
